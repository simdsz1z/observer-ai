# Security and privacy reports

For a vulnerability that could expose local data or bypass capture consent, use [GitHub private vulnerability reporting](https://github.com/simdsz1z/observer-ai/security/advisories/new). Avoid posting sensitive reproduction data in a public issue.

Include the affected version, Windows version, reproduction steps using synthetic data, and expected versus actual behavior. Do not attach credentials, private screenshots, or your memory database. Ordinary bugs and feature requests belong in public issues.

This is an early project. Privacy checks are best effort, local data is not encrypted by the app, and model output is untrusted. The latest published version is the current maintenance target.
